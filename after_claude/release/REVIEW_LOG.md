# 검토 기록

1. 원자료 검증: 900개 후보 성능 시도의 개수·예정 시각·시간 계산·협상 코드·인증서 식별자·재개 여부를 검사하고 정책을 재평가했다. 지연 후보 거절, 정상 두 후보 승인과 기록된 판정의 일치를 확인했다.
2. 복구 검증: 150개 장애 관측 시도를 재분류했다. 장애 대상 성공23회, 실패21회, 복구 대상 성공106회다. 마지막20회 복구 대상 성공, 고전 암호 복귀 거절, 잘못된 인증서·오래된 상태 증적 거절을 확인했다. 복구2.951초는 제어기 관측이며 장애 주입 요청 및 SSH 왕복을 포함한다.
3. 표현·산출물 검토: 한국어/영어 보고서와 그림을 생성했다. 순수 TLS 호출 시간과 예정 접속부터 프로세스 종료까지 시간을 분리하고, 인위적350ms 지연 및 서비스 배포 버전 의미를 명시했다. 한글 렌더링·그림 범례·로컬 링크와 공개 JSON의 주요 비밀정보 패턴을 확인했다.

Mac 에뮬레이션 전체 시험에서 정상 후보가 성능 기준을 초과한 실패 기록은 로컬 artifacts/local-release-20260924T170605Z에 보존한다. 이를 AWS 결과에 합산하지 않는다. 기준은 완화하지 않았다. 이번 결과는 단일 AWS 실행의 기능 검증이며 무중단·운영 처리량 주장으로 사용하지 않는다.

공개 설명에서 내부 배포 번호를 제거했다. 후보 승인 단계는 최초 KPQC 배포 후보·후속 업데이트 후보, 복구 단계는 신규 배포 서비스·이전 승인 서비스로 표기한다. 한국어·영어 보고서와 그림을 재생성하고 범례와 문장을 확인했다. 원자료의 식별자는 재현성을 위해 보존한다.
