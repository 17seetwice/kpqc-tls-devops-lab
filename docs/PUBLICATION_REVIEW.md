# 공개 문서 3차 검토 기록

검토일: 2026-09-24 · 상태: 사용자 검토 대기 · 신규 AWS 실행 및 GitHub 업로드 보류

## 검토 대상

한국어·영어 README, 기술보고서, 배포 아키텍처 및 워크플로, `after claude`의 기존 결과·그림·공개 증적, 해당 측정·정책 코드. 세 차례 검토는 동일 작성자의 순차 검토이며 독립 심사나 보안 인증을 의미하지 않는다.

## 1차 — 수치 및 증적 정합성

- 공개 원기록 1,935개 연결에서 성공 여부, TLS 버전·cipher, 인증서 검증, 재개 없음 및 HRR 0을 확인하였다.
- 양 끝의 방향별 핸드셰이크 메시지 바이트 대응을 대조하였다.
- 129개 요약 행의 표본 수와 핸드셰이크·양측 CPU·양측 RSS 중앙값을 재계산하여 CSV와 대조하였다.
- 메모리 기록의 RSS 최고 기록 재설정 성공과 증가량 산식을 확인하였다.
- 최종 AWS 게이트 63개 assertion의 통과 및 활성 경로 표본 69회·실패 0회를 확인하였다.
- 공개 데이터 사본의 SHA-256 목록을 대조하였다.

결과: 기존 기록과 집계 수치 일치. 표의 범위를 구성별 중앙값 범위로 명시하고, 시간 분석 1,290회·메모리 분석 129회·준비 및 감시 516회를 구분하였다.

## 2차 — 코드 및 주장 범위

- `tls_handshake.c`, `extended_handshake.py`의 측정·반복 구조와 문서 정의를 대조하였다.
- `gate_policy.py`, `gate_worker.py`, `gate_suite.py`에서 정책 판정, 후보 경로, 부정 프로브와 증적 연결 구조를 확인하였다.
- 실제 후보 시험은 TCP 라우터의 후보 경로를 사용한다. 그림에서 이 경로와 활성 경로를 구분하였다.
- 최신 로컬 제어 AWS 실행과 과거 GitHub Actions 실행의 결과를 구분하였다.
- 과거 미커밋 소스를 이후 문서 커밋과 동일한 실행 소스로 주장하지 않는다.
- 단일 실행·고정 모드 순서·순차 서버·직접 신뢰 리프·메모리 n=3의 해석 범위를 기재하였다.

회귀 확인: 정책 단위시험 6개 및 EC2 정리 단위시험 4개 통과. 새 Docker 이미지 빌드는 성공했으나, 로컬 Docker의 `parent snapshot ... does not exist` 오류로 컨테이너 실행이 시작되지 않았다. 따라서 이번 개정의 새 통합시험은 미완료이며 과거 63항목 통과 기록으로 대체 주장하지 않는다. 업로드 승인 후 새 원격 CI에서 확인할 항목이다.

## 3차 — 출판 구성 및 표시

- README는 개요·시스템·실험·자동화·재현·범위 순서로 구성하고 상세 방법은 기술보고서로 연결하였다.
- 한영 문서의 주요 수치, 표본 수, 정책 의미 및 실행 상태를 맞추었다.
- 그림의 제목·축·범례는 간결하게 유지하고 측정 조건과 한계는 캡션·본문에 배치하였다.
- 워크플로의 빌드·시험, OIDC 인증, SSH 배포를 별도 단계로 표시하였다.
- Mermaid 한영 워크플로를 PNG·SVG로 렌더링하고 표시를 확인하였다.
- 문서의 로컬 링크와 공개 후보 파일의 키·토큰·AWS 리소스 식별자 패턴을 점검하였다.
- 문서를 사용자 검토용 개정안으로 표시하여 새 원격 CI가 이미 실행된 것처럼 보이는 문장을 제거하였다.

## 사용자 확인 후 절차

내용 확인 → 최종 공개 파일 목록 검토 → 원격 README 이력을 보존한 병합 완료 → 업로드 → 새 CI 확인 → 승인한 후속 시뮬레이션 수행 순으로 진행한다. 현재 원격 main은 `8beca90`이며 로컬 개정안은 업로드하지 않았다. 원격 병합은 로컬에서 시작되었으나 아직 완료 커밋을 만들지 않은 상태다.

사용자에게 확인받을 핵심은 README의 설명 수준, 기술보고서의 범위·결과 표현, 아키텍처의 가독성이다. 연구 결과의 한계는 삭제하지 않고 본문과 캡션에 적절히 배치한다.

## 사용자 검토 반영 후 진행

사용자가 용어 및 메모리 해석 보완을 확인한 뒤 기존 작업의 계속 진행을 요청하였다. 측정 보완 문서를 포함하여 업로드하고 새 CI를 확인한다. 이후 기존 두 EC2로 모드 순서 무작위화 반복 측정을 진행한다. 새 인스턴스 생성 및 신규 메모리 결과 공개는 이번 단계에 포함하지 않는다.
