# 추가 실험: 네트워크 조건과 부하 중 배포

상태: 구현 및 사전 검증 중. 새로운 AWS 실측 결과는 아직 없음.

[실험 설계](../../docs/SYSTEMS_EXPERIMENT_PLAN.md)

1. MTU (Maximum Transmission Unit) 1500/9001 및 추가 네트워크 지연 비교
2. HRR (HelloRetryRequest) 발생 유무에 따른 핸드셰이크 비교
3. 병렬 서버의 동시 접속·처리량 측정
4. 동시 접속 중 부적합 후보 거절과 정상 후보 배포 전환

기존 EC2 두 대를 사용하고 종료 후 중지한다. 인증서 체인 실험은 이번 범위에서 제외한다. 기존 결과와 새 결과를 혼합하지 않는다.
