# TLS 성능·네트워크 측정

이 묶음은 KPQC TLS 핸드셰이크 시간과 자원·네트워크 특성을 측정합니다. 성능 벤치마크 자체는 배포 정책을 실행하거나 배포·복구 절차를 검증하지 않습니다.

- [초기 성능 실험](initial/README.md): 환경, 방법, 초기 원자료와 그래프.
- [프로세스 초기화·설정 재사용 비교](process-reuse/README.md): 43개 구성의 순서 균형화 측정.
- [네트워크·동시 부하 측정](network-and-load/README.md): MTU, 추가 지연, HRR, 처리량. 이 보고서에는 별도의 부하 중 배포 전환 항목도 기록되어 있습니다.
